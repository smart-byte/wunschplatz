# Illustrations

These decorative images were generated with OpenAI image generation in September
2026 and encoded as WebP. The illustrated people and school scenes are synthetic.

| Asset                  | Use                                                                       |
| ---------------------- | ------------------------------------------------------------------------- |
| `school-garden.webp`   | Landing page: ceramics at the schoolhouse and gardening by the greenhouse |
| `projects-empty.webp`  | Empty projects page: a creative workshop                                  |
| `projects-filled.webp` | Projects table: models and workshop materials                             |
| `students-empty.webp`  | Empty students page: a school library                                     |
| `students-filled.webp` | Students table: small study groups                                        |

Cropping, opacity, and fades are defined in
[school-garden.css](../components/landing/school-garden.css) and
[workspace-backdrop.css](../components/layout/workspace-backdrop.css).
The decorative backgrounds are hidden on mobile.
